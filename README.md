# Analiza Datelor FAO folosind FP-Growth

Acest repository conține codul sursă pentru proiectul de Învățare Automată.

**Descriere:**
Codul compară performanța algoritmilor Apriori și FP-Growth pe un set de date tranzacțional (simulat pe structura FAO Liban) și extrage reguli de asociere nutriționale.

**Fișiere:**
* `Proiect_IA_FAO.ipynb`: Codul sursă complet (Python/Jupyter Notebook).
* `rezultate_proiect.csv`: Regulile de asociere extrase (Top 10).

**Rezultate Cheie:**
Algoritmul FP-Growth s-a dovedit a fi de 50x mai rapid decât Apriori la un suport de 1%.
